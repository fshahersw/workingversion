# Synthetic Office acceptance outputs

These small files were produced by local synthetic acceptance workflows. They contain no firm/client data and no API keys. The Tesla workbook contains **mock data**, not actual Tesla financial results.

| File | Intended review |
| --- | --- |
| `writer-selection-verified.docx` | Targeted selected-text removal, preserved surrounding native document/table structure. |
| `writer-rebuilt-verified.docx` | Explicit body replacement with a one-page layout and native table. |
| `mock-tesla-2021-2025.xlsx` | Twenty-quarter multi-sheet workbook with formulas and native charts, including correction/preservation checks. |
| `pdf-native-edit-verified.pdf` | Actual source text edit with preserved page box and notes. |
| `pdf-extract-verified.pdf` | Separate extracted Library artifact, with source text/page/notes retained. |

`manifest.json` records byte sizes and SHA256 hashes. Verify those hashes before importing. Existing local document IDs in historical reports will not exist in a fresh environment: upload these files to create your own synthetic Library documents.

These are observed workflow outputs from the implementation work, not a claim that every file was generated at the final source commit or that Microsoft desktop interoperability has been certified. Rerun the [handoff acceptance matrix](../../docs/office-external-agent-handoff.md#8-verification-commands-and-acceptance-matrix). The large Word fixture is generated by `scripts/verify-writer-large-save-local.mjs`; its dependent creation check is `scripts/verify-large-create-local.mjs`.
