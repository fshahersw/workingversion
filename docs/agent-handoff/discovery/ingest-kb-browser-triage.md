The harness uses the checkout's normal Vite configuration (`tests/support/browser-server.ts`; `scripts/serve-browser-tests.mjs:6–13`), with HMR disabled. The bounded conclusion is **local native app bootstrap/build-transform integration is blocked**, specifically an un-replaced TanStack client environment constant in three tests. It is not yet established whether the source is a Vite/TanStack dependency incompatibility, optimization/define configuration, or a harness-specific transform difference. Check the production-built browser bundle separately; the dev trace alone cannot establish production behavior.
